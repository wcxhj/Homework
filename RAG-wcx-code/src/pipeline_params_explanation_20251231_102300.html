pipeline.py 参数详解

生成时间：2025年12月31日 10:23:00

参数配置说明

参数名 类型 默认值 说明
use_serialized_tables bool False 是否使用序列化的表格数据。如果为True，系统会将表格内容转换为上下文独立的信息块，便于检索和理解。
parent_document_retrieval bool False 是否启用父文档检索。如果为True，在检索文本块后会返回整个父页面内容，而不是仅返回匹配的文本块。
use_vector_dbs bool True 是否使用向量数据库进行检索。如果为True，系统会使用FAISS向量数据库进行相似度检索。
use_bm25_db bool False 是否使用BM25数据库进行检索。如果为True，系统会使用传统的BM25算法进行检索，通常用于混合检索策略。
llm_reranking bool False 是否启用大语言模型重排。如果为True，系统会在检索后使用LLM对检索结果进行相关性重排，提高结果质量。
llm_reranking_sample_size int 30 LLM重排的样本大小。在进行LLM重排时，会先从向量检索中获取此数量的候选文档，然后通过LLM进行重排。
top_n_retrieval int 10 检索返回的文档数量。系统将返回最相关的top_n个文档片段供后续处理使用。
parallel_requests int 1 并行请求数量。用于控制API调用的并发数，限制可防止API超出调用频率限制（如qwen-turbo的阈值）。
pipeline_details str "" 流水线详情描述。用于记录当前配置的流水线处理细节，便于后期分析和调试。
submission_file bool True 是否生成提交文件。如果为True，系统会生成符合比赛或项目要求的格式化提交文件。
full_context bool False 是否使用完整上下文。如果为True，系统会检索文档的全部内容而不是仅匹配的片段。
api_provider str "dashscope" API提供商。指定使用的LLM服务提供商，如"dashscope"（阿里云通义千问）、"openai"、"ibm"、"gemini"等。
answering_model str "qwen-turbo-latest" 问答模型名称。指定用于生成答案的具体模型，如"qwen-turbo-latest"、"gpt-4o-mini-2024-07-18"、"gpt-4o-2024-08-06"等。
config_suffix str "" 配置后缀。用于区分不同配置生成的文件，避免命名冲突。

配置使用场景

这些参数通过 RunConfig 类进行配置，可以根据不同需求组合使用：

  • 基础配置 (base): 使用向量数据库，生成提交文件，使用GPT-4o-mini模型
  • 父文档检索配置 (pdr): 启用父文档检索，使用GPT-4o模型
  • 最大配置 (max): 启用LLM重排，使用qwen-turbo模型
