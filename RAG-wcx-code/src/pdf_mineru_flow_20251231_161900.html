PDF MinerU 本地处理流程

原始流程

flowchart TD A[本地PDF文件] --> B[手动上传到OSS服务器] B --> C[获取远程URL] C --> D[调用MinerU API
https://vl-image.oss-cn-shanghai.aliyuncs.com/pdf/ + 文件名] D --> E[获取Task ID] E --> F[查询任务状态] F --> G{任务完成?} G -->|是| H[下载结果ZIP] G -->|否| I[等待并重试] I --> F H --> J[解压结果]

改进后流程

flowchart TD A[本地PDF文件路径] --> K[自动检测路径类型] K -->|本地路径| L[尝试上传本地文件] K -->|文件名| M[使用原始远程URL模式] L --> N[获取远程访问URL] N --> O[调用MinerU API
使用获取的URL] M --> O O --> P[获取Task ID] P --> Q[查询任务状态] Q --> R{任务完成?} R -->|是| S[下载结果ZIP] R -->|否| T[等待并重试] T --> Q S --> U[解压结果]

关键改进点

  1. 本地文件支持：直接传入本地PDF路径，无需手动上传
  2. 智能路径检测：自动判断输入是本地路径还是远程文件名
  3. 向后兼容：保留原有API接口，不影响现有代码
  4. 错误处理增强：添加API响应验证和详细日志
  5. 集成优化：与Pipeline无缝集成

API接口

  • get_task_id(file_name_or_path) - 智能获取任务ID
  • get_result(task_id) - 获取任务结果
  • unzip_file(zip_path) - 解压结果文件
